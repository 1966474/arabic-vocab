# Ed's Jordanian Arabic Vocabulary App

## Upload to GitHub
1. Open your empty `arabic-vocab` repository.
2. Tap **uploading an existing file**.
3. Unzip the downloaded ZIP file first.
4. Select and upload **all files and the `icons` folder** from inside the `arabic-vocab-app` folder.
5. Commit the files.

## Turn on GitHub Pages
1. In the repository, open **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Tap **Save**.
6. GitHub will show the website address after it deploys.

## Add to iPhone Home Screen
1. Open the GitHub Pages website in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Name it `Arabic Vocab`, then tap **Add**.

The app includes search, categories, favorites, learned-word tracking, flashcards,
speech playback, dark mode, offline support, and the ability to add words on the phone.
